# 사용 설명서

## 팝업 화면 구성

확장 아이콘을 누르면 4개 탭이 있는 팝업이 열립니다. 상단에는 항상 **수집 스위치**와 현황(수집 건수 / 스캔 건수 / 최근 수집 시각)이 보입니다.

threads.com 이 아닌 탭에서 열면 “threads.com 탭에서 열어야 수집이 동작합니다” 안내와 함께 피드로 바로 가는 링크가 뜹니다.

---

## 1. 수집 탭

| 항목 | 설명 | 기본값 |
|---|---|---|
| 자동 스크롤로 계속 수집 | 피드를 알아서 내리며 계속 모읍니다. 켜두고 다른 일을 해도 됩니다. | 꺼짐 |
| 스크롤 간격 | 한 번 내리고 다음까지 기다리는 시간. 짧을수록 빠르지만 부담이 큽니다. | 2500ms |
| 수집된 글을 페이지에서 표시 | 매칭된 글에 파란 테두리와 `수집됨` 뱃지를 붙입니다. | 켜짐 |
| 최소 글자 수 | 이보다 짧은 글은 아예 무시합니다. | 10자 |
| 추천 재계산 주기 | 스캔 N건마다 새 키워드 후보를 다시 뽑습니다. | 60건 |

맨 아래 **검색 열기**는 승인된 키워드 중 하나를 골라 쓰레드 검색 결과 페이지를 새 탭으로 엽니다.
피드를 훑는 것보다 특정 키워드를 집중적으로 모을 때 훨씬 빠릅니다.

> 스크롤 간격을 1초 미만으로 두지 마세요. 요청이 몰리면 계정에 일시 제한이 걸릴 수 있습니다.

---

## 2. 키워드 탭

그룹 단위로 켜고 끕니다.

- **수집중** 뱃지 = 컨펌된 그룹. 이 그룹의 키워드만 실제로 매칭에 쓰입니다.
- **컨펌 대기** 뱃지 = 내가 추천만 해둔 그룹. `승인`을 눌러야 반영됩니다.
- 각 키워드 옆 `×` 로 개별 삭제, 맨 아래 입력창으로 직접 추가할 수 있습니다.
  직접 추가한 키워드는 `내가 추가한 키워드` 그룹에 모입니다.

키워드는 띄어쓰기를 신경 쓰지 않아도 됩니다. `어디서 사셨어요` 로 넣든 `어디서사셨어요` 로 넣든
내부적으로 공백·문장부호·이모지를 지운 형태로 비교합니다.

전체 목록은 [KEYWORDS.md](KEYWORDS.md) 참고.

---

## 3. 추천 탭 — 컨펌 흐름

수집한 글에서 자주 나오는 2~3어절 표현 중, 구매의도와 관련된 것만 후보로 올라옵니다.

각 후보에는 **몇 번 나왔는지**, **점수**, **실제 문장 예시**가 함께 표시됩니다.

- `승인` → `내가 추가한 키워드` 그룹에 들어가고, 그때부터 수집에 쓰입니다.
- `거절` → 거절 목록에 기록되어 **다시는 추천되지 않습니다.**
- `지금 다시 뽑기` → 재계산 주기를 기다리지 않고 즉시 후보를 갱신합니다.

**승인하지 않은 후보는 어떤 경우에도 수집에 반영되지 않습니다.** 후보가 쌓여도 결과가 바뀌지 않습니다.

후보가 안 나온다면 대부분 표본이 부족한 경우입니다. 같은 표현이 **2번 이상** 나와야 후보가 됩니다.

## 4. 결과 탭

- 상단 드롭다운으로 그룹별 필터. 옆의 `CSV` / `JSON` / `MD` 버튼은 **현재 필터가 적용된 결과만** 내보냅니다.
- 검색창으로 본문·작성자 내 검색.
- 글마다 작성자 링크(새 탭), 매칭된 키워드 하이라이트, 좋아요 수, 외부 링크 개수, 작성 시각이 보입니다.
- `삭제`는 그 글 하나만, `전체 삭제`는 수집 결과 전체를 지웁니다. **키워드 설정은 지워지지 않습니다.**

## 자주 겪는 문제

| 증상 | 원인과 해결 |
|---|---|
| 수집을 켰는데 아무것도 안 쌓임 | ① 쓰레드 탭이 아님 ② 승인된 그룹이 하나도 없음 ③ 피드에 해당 표현이 실제로 없음. `검색 열기`로 키워드 검색부터 해보세요. |
| 확장을 고쳤는데 반영이 안 됨 | `chrome://extensions` 에서 새로고침(↻) 후, 쓰레드 탭도 새로고침하세요. |
| 같은 글이 여러 번 쌓임 | 글 ID 기준으로 중복 제거하므로 정상적으로는 발생하지 않습니다. 발생한다면 쓰레드 DOM 구조가 바뀐 신호입니다 (`content.js` 의 추출 로직 확인). |
| 엉뚱한 글이 잡힘 | `키워드` 탭에서 해당 키워드를 지우거나, `extension/src/keywords.js` 의 `exclude` 에 제외어를 추가하세요. |
| 갑자기 아무 글도 안 잡힘 | 쓰레드가 DOM 구조를 바꿨을 수 있습니다. `content.js` 의 `POST_HREF` 와 `postContainer()` 를 점검하세요. |

## 데이터가 저장되는 곳

전부 `chrome.storage.local` 입니다. 외부로 전송되지 않습니다.

| 키 | 내용 |
|---|---|
| `groups` | 키워드 그룹 + 승인 상태 |
| `posts` | 수집한 글 (기본 상한 5000건, 넘으면 오래된 것부터 삭제) |
| `suggestions` | 컨펌 대기 중인 추천 후보 |
| `rejectedSuggestions` | 거절한 후보 (재추천 차단) |
| `settings` | 수집 옵션 |
| `stats` | 스캔/수집 카운터 |
| `corpus` | 추천 발굴용 최근 본문 400건 |

확장을 삭제하면 이 데이터도 함께 사라집니다. 중요한 결과는 `JSON` 으로 내보내 두세요.
