# 설치 가이드

크롬 웹스토어에 올라간 확장이 아니라 **폴더를 직접 불러오는 방식**입니다.
git 없이 zip 하나만 받아도 설치할 수 있습니다.

---

## 어느 방법으로 받을까

| 상황 | 방법 |
|---|---|
| 개발/수정도 할 컴퓨터 | [A. git clone](#a-git-clone-개발용) |
| 그냥 쓰기만 할 컴퓨터 (윈도우 등) | [B. zip 내려받기](#b-zip-내려받기-사용만-할-때) ← **간단** |

---

## A. git clone (개발용)

```bash
git clone https://github.com/sskk22000-dotcom/threads-collector.git
```

불러올 폴더는 저장소 안의 **`extension`** 폴더입니다. 아래 [크롬에 불러오기](#크롬에-불러오기)로 이동.

---

## B. zip 내려받기 (사용만 할 때)

1. **릴리스 페이지**에서 최신 zip 을 내려받습니다.
   👉 https://github.com/sskk22000-dotcom/threads-collector/releases/latest
   `threads-collector-vX.Y.Z.zip` 파일을 클릭하면 받아집니다.

2. **압축을 풀 위치를 정합니다. 여기가 제일 중요합니다.**
   크롬은 이 폴더를 계속 참조하기 때문에 **폴더를 지우거나 옮기면 확장이 죽습니다.**
   `다운로드` 폴더는 정리하다가 지우기 쉬우니 피하세요.

   - 윈도우 권장 위치: `C:\Users\<내이름>\chrome-extensions\`
   - 맥 권장 위치: `~/Applications/chrome-extensions/`

3. 압축을 풉니다.

   **윈도우**
   - 받은 zip 을 **마우스 오른쪽 클릭 → 속성** → 아래쪽에 **"차단 해제"** 체크박스가 보이면 체크하고 확인
     (인터넷에서 받은 파일이라 윈도우가 잠가두는 경우가 있습니다. 안 보이면 그냥 넘어가세요.)
   - 다시 오른쪽 클릭 → **압축 풀기** → 위 2번에서 정한 폴더 지정
   - 풀고 나면 `threads-collector-v2.1.0` 폴더가 생기고, 그 안에 `manifest.json` 이 보여야 합니다.

   **맥**
   ```bash
   mkdir -p ~/Applications/chrome-extensions
   unzip ~/Downloads/threads-collector-v*.zip -d ~/Applications/chrome-extensions/
   ```

4. 아래 [크롬에 불러오기](#크롬에-불러오기)로 이동. 불러올 폴더는 **`manifest.json` 이 들어있는 폴더**입니다.

---

## 크롬에 불러오기

두 방법 모두 여기서부터는 똑같습니다.

1. 크롬 주소창에 `chrome://extensions` 를 입력하고 엔터
   (또는 우측 상단 ⋮ → 확장 프로그램 → 확장 프로그램 관리)
2. **오른쪽 위 "개발자 모드" 스위치를 켭니다.**
3. 왼쪽 위에 나타난 **"압축해제된 확장 프로그램을 로드합니다"** 버튼 클릭
   (영문판이면 `Load unpacked`)
4. 폴더 선택창에서 **`manifest.json` 이 들어있는 폴더**를 고릅니다.
   - git clone 했다면 → `threads-collector/extension`
   - zip 을 풀었다면 → `threads-collector-v2.1.0`
   - ⚠️ 폴더 **안으로 들어가서** 선택하지 말고, 그 폴더 자체를 선택하세요. `src` 폴더를 고르면 안 됩니다.
5. 목록에 **쓰레드 레퍼런스 수집기**가 나타나면 설치 완료.
6. 주소창 오른쪽 퍼즐(🧩) 아이콘 → 목록에서 이 확장의 **압정(📌)** 을 눌러 툴바에 고정하면 편합니다.

## 잘 됐는지 확인

1. https://www.threads.com 접속 (로그인 상태여야 합니다)
2. 툴바의 돋보기 아이콘 클릭 → 상단 **수집** 스위치 켜기
3. 피드를 스크롤 → 구매 관련 글에 **파란 테두리 + `수집됨` 뱃지**가 붙으면 정상
4. 아무것도 안 잡히면 팝업 `수집` 탭 아래 **검색 열기**로 `구매처` 를 검색해보세요

## 자주 나오는 문제

| 증상 | 해결 |
|---|---|
| "매니페스트 파일이 없거나 읽을 수 없습니다" | 폴더를 잘못 골랐습니다. `manifest.json` 이 **바로 보이는** 폴더를 선택하세요. |
| 크롬 켤 때마다 "개발자 모드 확장 프로그램을 사용 중지하세요" 창이 뜸 | 개발자 모드 설치의 정상 동작입니다. **X 로 닫으면** 확장은 그대로 동작합니다. "사용 중지"를 누르면 꺼지니 주의하세요. |
| 어느 날 갑자기 확장이 사라짐 | 압축 푼 폴더를 지우거나 옮긴 경우입니다. 폴더를 되돌리거나 다시 불러오세요. |
| 확장은 있는데 아무것도 안 잡힘 | ① threads.com 탭이 맞는지 ② 팝업 `수집` 스위치가 켜져 있는지 ③ `키워드` 탭에 **수집중** 그룹이 하나라도 있는지 확인 |
| 윈도우에서 압축 풀기가 실패 | zip 을 오른쪽 클릭 → 속성 → **차단 해제** 체크 후 다시 시도 |

## 업데이트

새 버전이 나오면:

- **git clone 한 경우** — `git pull` 후 `chrome://extensions` 에서 해당 확장의 **새로고침(↻)** 버튼 클릭
- **zip 으로 설치한 경우** — 새 zip 을 받아 **같은 위치에 덮어쓴 뒤**, `chrome://extensions` 에서 새로고침(↻)
  (버전 폴더 이름이 바뀌었다면 기존 것을 **삭제**하고 새 폴더로 다시 불러오세요)

수집한 글과 키워드 설정은 확장을 새로고침해도 **유지됩니다.** 단, 확장을 **삭제**하면 함께 지워지니
중요한 결과는 미리 `결과` 탭에서 `JSON` 으로 내보내 두세요.

## 컴퓨터 두 대에서 쓸 때

수집 데이터와 키워드 설정은 **각 컴퓨터의 크롬 안에 따로 저장됩니다.** 자동으로 동기화되지 않습니다.
한쪽에서 키워드를 승인해도 다른 쪽에는 반영되지 않으니, 각 컴퓨터에서 따로 컨펌해 주세요.
수집 결과는 `결과` 탭 → `JSON` / `CSV` 로 내보내 옮기면 됩니다.
